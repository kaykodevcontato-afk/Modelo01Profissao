# Site demonstrativo — Bárbara Rodrigues | Dev Kayko

Modelo de apresentação profissional e portfólio, com a fotografia, assinatura e vídeo fornecidos. **Não é um site oficial de agendamento.**

## GitHub Pages
1. Extraia o ZIP. Envie `index.html`, `style.css`, `script.js` e a pasta `assets` para a raiz do repositório.
2. No GitHub, vá em **Settings > Pages > Deploy from a branch**, escolha `main` e `/ (root)`.
3. Abra a URL publicada.

## O que foi ajustado
- Faixa discreta identificando o modelo demonstrativo.
- Botão de agendamento abre uma janela com exemplo da mensagem, **sem enviar para WhatsApp** e sem aviso técnico.
- Foto, vídeo e assinatura originais preservados, inclusive a reprodução do vídeo com retorno à foto.
- Seção de portfólio no final, com explicação do modelo.
- Responsividade mantida.

## Antes de divulgar publicamente
Obtenha autorização da profissional para usar imagem, vídeo, nome e identificação profissional como portfólio; confirme os textos e o CRP. Para converter em site oficial, será necessário habilitar contato real e revisar as informações.
